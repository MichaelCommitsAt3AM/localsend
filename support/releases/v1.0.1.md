# LocalSend AutoSync 1.0.1

This update improves local device discovery after the mobile app has been running
for a long time and makes Android clipboard image-arrival notifications silent.

## Fixes

- Refresh reloads current network addresses and rebuilds discovery sockets before
  scanning, recovering from stale Wi-Fi interfaces and suspended sockets.
- Android now rebuilds discovery sockets when the app resumes, as iOS already does.
- Discovery listener errors trigger recovery. Failed scans clear their loading
  state so another scan can run.
- Android clipboard image arrivals remain visible in notifications without sound
  or vibration. Existing installations migrate to the silent notification channel.

## Downloads

- `LocalSend-1.0.1-android-arm64-v8a.apk`: signed Android ARM64 release APK.
- `LocalSend-1.0.1-windows-x86-64.exe`: Windows x64 installer.
- `LocalSend-1.0.1-windows-arm-64.exe`: Windows ARM64 installer.

Install over the previous AutoSync release to retain settings and pairing.
The debug Android app uses a separate package and is not upgraded by the release APK.
Windows installers are unsigned.

## Validation

Seven regression tests cover discovery restart races, startup and listener failures,
and clearing failed scan state. Static analysis and formatting checks passed.
The Android debug build was tested on a Galaxy A35 running Android 16 and confirmed
working. Extended background reliability across other phones remains unverified.
