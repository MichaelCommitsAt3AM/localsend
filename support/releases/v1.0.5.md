# LocalSend AutoSync 1.0.5

This update restores clipboard sync on Android 17 and adds a way to retry an offline paired device. Android build number: 70.

## Changes

- Allow the Shizuku clipboard service to run on Android 17 when the required permissions are granted.
- Add **Retry connection** to the details of an offline paired device. The app verifies a discovered device's pinned identity before updating its address. Other clipboard connections may briefly restart during a retry.

## Downloads

- `LocalSend-1.0.5-android-arm64-v8a.apk`: signed Android ARM64 release APK.
- `LocalSend-1.0.5-windows-x86-64.exe`: Windows x64 installer.
- `LocalSend-1.0.5-windows-arm-64.exe`: Windows ARM64 installer.

Install over the previous AutoSync release to retain settings and pairing. Windows installers are unsigned.

## Validation

On a Galaxy A35 running Android 17, the Shizuku clipboard helper started and the paired Windows device connected. The user confirmed text clipboard sync in both directions. Focused tests cover the retry control and authenticated address refresh. The cause of similar failures before the Android 17 upgrade remains unconfirmed.
