# LocalSend AutoSync 1.0.2

This update fixes Android clipboard access setup and makes clipboard sync status
clearer on the Receive screen and in notifications.

## Changes

- Set up access opens Shizuku when it needs to be started or its authorization
  restored. Compatible manager variants are discovered instead of relying only
  on the standard package name. If none is found, the app explains how to continue.
- Dismissing the Android clipboard sync notification restores it while sync is
  running. The Stop action still stops syncing and removes the notification.
- After 30 seconds without a connected paired device, clipboard settings and the
  Android notification explain possible public or guest Wi-Fi restrictions and
  suggest a private network or hotspot. This is connection guidance, not proof of
  network isolation: paired devices may also be asleep or have syncing disabled.
- The Receive screen lists connected clipboard sync devices while sharing is
  active. The note disappears when sharing stops or the devices disconnect.

## Downloads

- `LocalSend-1.0.2-android-arm64-v8a.apk`: signed Android ARM64 release APK.
- `LocalSend-1.0.2-windows-x86-64.exe`: Windows x64 installer.
- `LocalSend-1.0.2-windows-arm-64.exe`: Windows ARM64 installer.

Install over the previous AutoSync release to retain settings and pairing.
The debug Android app uses a separate package and is not upgraded by the release APK.
Windows installers are unsigned.

## Validation

28 focused tests passed, including authorization handling, the network warning,
Receive status visibility, and translation checks. Flutter analysis and Android
compilation passed. The Android debug app was tested on a Galaxy A35 running
Android 16 and confirmed working by its user. Other Shizuku variants and phones
have not been individually verified.
