# LocalSend AutoSync 1.0.3

This update fixes clipboard reconnection after changing Wi-Fi networks and two
Windows installer issues. Android build number: 68.

## Changes

- Clipboard sync refreshes a paired device's saved IPv4 address through normal
  LocalSend discovery. A TLS handshake must verify the paired clipboard
  certificate before the address changes. Pairing, device names, sharing
  directions, and image settings are preserved. Update both devices for automatic
  recovery when their addresses change.
- Windows handles confirmed installer shutdown requests even when minimize to
  tray is enabled. Installers also enable Restart Manager's force-close fallback
  for older running versions. Finish active transfers before updating.
- Windows installers retain the tray icon asset. The installer previously
  excluded every file named logo.ico, including the runtime tray icon; the
  exclusion now applies only to the setup icon at the payload root.

## Downloads

- `LocalSend-1.0.3-windows-x86-64.exe`: Windows x64 installer.

Install over the previous AutoSync release to retain settings and pairing.
The debug Android app uses a separate package and pairing configuration.
Windows installers are unsigned.

## Validation

35 focused tests passed, including real mutual TLS probes, rejection of unpaired
certificates, address persistence, and disabling or revoking pairing during a
probe. Dart analysis passed. Windows and Android debug apps were launched on the
development laptop and Galaxy A35, and the user confirmed the fixes working.
The changed Windows runner also compiled independently. An end-to-end installer
upgrade over an older tray instance has not yet been verified.
